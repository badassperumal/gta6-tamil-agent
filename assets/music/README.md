# Background music (optional)

Drop royalty-free `.mp3` / `.m4a` tracks here and commit them. The editor picks one at random for each video and mixes it under the voice at `music_volume` from config.yaml.

Safe free sources:
- YouTube Studio → Audio Library (filter: "Attribution not required")
- Pixabay Music (CC0-style licence)

Never use film songs or tracks from other YouTube videos. They trigger Content ID claims.
