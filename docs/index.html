GTA6 Tamil Agent

GTA6 Tamil Agent is a private automation tool used only by its owner to manage the owner's own YouTube channel, which covers GTA 6 news, tips and gameplay in Tamil.

It uses the YouTube Data API and YouTube Analytics API to upload the owner's videos, set thumbnails, organise playlists, reply to comments on the owner's channel and read the channel's own analytics. It is not offered to other users.
