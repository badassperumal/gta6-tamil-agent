Privacy Policy

Last updated: 18 November 2026

GTA6 Tamil Agent ("the app") is a private tool operated by its owner to manage the owner's own YouTube channel. It has no other users.

This app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Your data is also covered by the Google Privacy Policy.

Data the app accesses

  • The owner's YouTube channel information, videos, playlists and analytics, through the YouTube API Services, so that it can upload videos, set thumbnails, add videos to playlists and measure performance.
  • Public comments posted on the owner's videos, so that it can reply to them and hold spam for review.

How data is used and stored

  • Data is used only to operate the owner's channel. It is never sold or shared with third parties for advertising.
  • Comment text may be processed by an AI language model to draft a reply. Only the comment text and the commenter's public display name are sent.
  • The app stores comment IDs it has replied to and aggregated channel statistics. It stores no personal profiles of viewers.
  • OAuth credentials are stored as encrypted secrets and are never published.
  • Data obtained from YouTube API Services is refreshed or deleted within 30 days.
  • The app has no website accounts and places no cookies, and it does not store or access information on users' devices.

YouTube, Google and revoking access

The app uses YouTube API Services. By interacting with the channel you are also subject to the YouTube Terms of Service and the Google Privacy Policy. The owner can revoke the app's access at any time at Google security settings.

Deleting data

When access is revoked at the Google security settings page, the app can no longer access any YouTube data, and all stored API data is deleted within 7 days. To ask for removal of any stored data related to your comments, email ananthece16@gmail.com. Requests are handled within 7 days.
